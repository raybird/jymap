# 《鴛鴦刀》年代複核

日期：2026-11-02。第三階段第三十一批，這部此前只做過第一輪與官歷補查。

結果：5筆由舊佔位1680改用區間帶「約1732至1737年間」，保留`年代待考`與`舊資料佔位`，`year`只作排序佔位，改為1736。座標不改，全站待查80筆、年份佔位32筆都不變。

## 為什麼現在才改

[2026-10-30補查](2026-10-30-yuanyang-chronology-followup.md)已查出1736至1737是官歷候選，但當時只能填單一年，所以保留1680，並要求有可靠編年才再開。第十六批加入區間帶後，不必定出確年就能表達這種情況，那項結案條件針對的是確年，本批沒有定確年。

1680本身不能成立：[劉於義wiki](https://zh.wikipedia.org/wiki/劉於義)記他1675年生、1712年進士，1680年才五歲。

| 乾隆元年署總督印務 | wiki、[《清實錄》高宗卷二十](https://zh.wikisource.org/wiki/清實錄/大清高宗純皇帝實錄/卷之二十) | 仍在任 |
| 乾隆二年召還 | 《清史稿》卷307 | 上限1737 |

下限取1732而不是1736：正文的「川陝總督」與他前期的「陝西總督」名目不同，小說官名未必精確，窄到1736至1737會排除雍正年間的讀法。wiki另記他1745、1746年署理直隸與直隸河道總督，與川陝無關，不列入。

## 今上是誰

正文說[今上當貝勒時已派人尋刀，接位後下密旨](https://github.com/OliverCWY/JY/blob/master/Markdown/新修版/鸳鸯刀/鸳鸯刀.md)，又說[追捕蕭義十六年](https://github.com/OliverCWY/JY/blob/master/Markdown/新修版/鸳鸯刀/鸳鸯刀.md)、[十六年前皇帝得知鴛鴦寶刀](https://github.com/OliverCWY/JY/blob/master/Markdown/新修版/鸳鸯刀/鸳鸯刀.md)。

| 讀法 | 相合 | 不合 |
| --- | --- | --- |
| 今上是雍正，1732至1735 | [1698年封貝勒、1709年封親王、其後接位](https://zh.wikipedia.org/wiki/雍正帝)，當過貝勒也下過密旨；十六年前是1716至1719，皇帝是康熙，與「十六年前皇帝得知」不衝突 | 「皇上追捕了十六年」要解成朝廷延續追捕 |
| 今上是乾隆，1736至1737 | 十六年前的皇帝同樣是別人 | [乾隆條目只記1733年封寶親王](https://zh.wikipedia.org/wiki/乾隆帝)，沒有貝勒 |

雍正讀法較順，但正文沒有帝名，本站不替作品補寫帝名，事件說明兩邊都寫。
