# 《神鵰俠侶》第二輪複核

日期：2026-11-02。第三階段第十七批，對象是尚未做過第二輪的21筆事件；另外7筆（020、021、023、059、088、090、185）與它們共用同一句年份說明，定位在前幾批已查過，本批只更新年份依據，一併列入。

結果：28筆都補正文依據，其中019、182由1236改為1237，16筆移除`代表年份`標籤，座標與朝代不改；情節與人物沒有發現需要更正的錯誤，只刪去058一句多餘的舊年份說明。全站257筆、待查80筆不變，時間軸1236組拆出1237組。

## 方法與限制

- 2026-11-02取得[金庸武俠網標稱新修版](https://www.jinyongbbs.com/jyxx/sdxl/)四十回加附錄、後記，共117頁、約100萬字，[來源分頁清單](2026-11-02-shendiao-source-manifest.json)列網址、擷取字數與HTML雜湊，不收錄全文。第一輪的九九藏書段落有打散及插字，本輪時序判斷改依這一版。
- 全書以紀年、人物年齡、經過年數、月份季節、懷孕線索做關鍵字掃描，再讀21筆所在章節的關鍵段落。這不是逐字通讀，也不是印本校勘。
- 寫入腳本要求每個新增來源都能在該頁找到錨點句，找不到就中止；28筆全數通過。
- wiki沒有給出中段的逐年年代，只有故事起訖。[神鵰俠侶條目](https://zh.wikipedia.org/wiki/神鵰俠侶)寫端平三年至開慶元年（1236至1259），新修版華山祭西毒北丐推遲至襄陽大戰翌年清明，故為1260。其餘年份由正文推算，仍保留`推算年份`。

## 已知年代問題

- 第16回「太后、大汗」並提，歷史上1243年蒙古由乃馬真后稱制、尚無大汗；第9回與第24回寫窩闊台死後皇后臨朝，與1243相合。作者第28回也註明全真諸子生卒與小說不同，不以史實倒改情節。
- 第26回小龍女追蹤「一月有餘」，第28回卻稱郭襄「生下不過一月」，兩者難以完全排進同一段時間，都在1243年內，不影響年份。
- 1236起點只有wiki與楊過年齡互證。郭芙第1回滿九歲，推到1259約三十二歲，第37回國師卻說她「總有三十五歲出頭」，這是人物口述的約數，也顯示前期年份不能算死，所以前期五筆保留`代表年份`。
