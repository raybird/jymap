# 《雪山飛狐》第二輪複核

日期：2026-11-02。第三階段第二十三批，也是《神鵰》之後六部第二輪的最後一批。

結果：8筆都補正文依據，年份、座標與標籤都不改，情節抽查沒有發現錯誤。115、138補上書內互證，仍保留`年代待考`。全站257筆、待查80筆不變。

## 方法與限制

- 2026-11-02取得[金庸武俠網標稱新修版](https://www.jinyongbbs.com/jyxx/xsfh/)十章加後記，共19頁、約13.5萬字，[來源分頁清單](2026-11-02-xueshan-source-manifest.json)列網址、擷取字數與HTML雜湊，不收錄全文。
- 全書以紀年、年齡、年距、月份做關鍵字掃描，再讀決定年份的段落。不是逐字通讀，也不是印本校勘。
- [作品條目](https://zh.wikipedia.org/wiki/雪山飛狐)寫乾隆四十五年三月十五日，以及「廿七年前」比武，與正文相同。

## 年代

| 主線 | [第1章乾隆四十五年三月十五](https://www.jinyongbbs.com/jyxx/xsfh/1353.html) | 1780年，全書當天 |

三條線索在書內彼此相合，1753在《雪山》內部已穩定。115、138仍保留`年代待考`，因為[飛狐兩書跨書編年](2026-10-30-feihu-chronology-followup.md)的衝突不是本書能解決的：《飛狐外傳》的十三歲、十八年前與紅花會六年／十年前，和《雪山》未統一。
