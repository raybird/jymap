# 自由查找與延伸探索實作

日期：2026-10-29。範圍：jymap。方向由使用者確認：先自由查找金庸世界，再透過人物與故事持續探索。

## 已完成的行為

- 搜尋以人物、小說與事件分組；空白查詢提供小說瀏覽與人物入口，人物入口只列事件較多的八人，完整人物名單透過搜尋查找。
- 搜尋範圍涵蓋全部作品；點選其他小說的事件時解除衝突的小說條件，顯示可關閉的變更提示，並取消待送出的舊範圍更新。
- 顯示目前小說、追蹤人物、時間範圍與視野內事件數；可個別移除條件或顯示全部。沒有符合條件的事件時，提供解除條件的按鈕。
- 返回上一步會恢復搜尋關鍵字與結果、篩選、選取事件、人物模式、地圖視角與時間軸捲動位置。探索記錄只保留於本次頁面生命週期。
- 人物年表可使用上一件／下一件，保持人物軌跡並同步定位事件；查看完整詳情後，可返回原人物與步驟。順序明確標示為「按年代探索」。
- 相關事件顯示共同人物、地點與時間關係等推薦理由，入口使用可由鍵盤操作的按鈕。
- 手機版詳情採底部面板，地圖依面板高度偏移目標位置；重新搜尋會暫時收起面板。桌面維持側欄。

## 限制與人工確認

2026-10-29 的環境未提供可用的視覺瀏覽器；自動化測試的外部圖磚載入已替換，因此不宣稱已完成截圖、實際手機或外部圖磚驗收。ChromeHeadless 實際最窄視窗為 485px，未涵蓋所有手機寬度。

人工確認步驟：

1. 啟動網站，確認外部圖磚正常；瀏覽小說後搜尋另一部小說的事件，確認提示、標記與詳情一致。
2. 搜尋人物並切換下一件，查看完整詳情後返回，確認人物進度、地圖與年表位置一致。
3. 返回搜尋結果，確認查詢內容與原先條件仍在；逐一解除條件並確認事件數更新。
4. 在實際手機及 390px 以下視窗，確認底部面板、輸入鍵盤、搜尋選項與內文捲動沒有遮蔽重要操作；另以鍵盤檢查選項及返回。

保留的建置警告：初始 bundle 超過 500 kB 警告預算、時間軸樣式超過 5 kB 警告預算、Leaflet 與 polyline decorator 的 CommonJS 相依。這批 App 樣式未新增超額警告。
