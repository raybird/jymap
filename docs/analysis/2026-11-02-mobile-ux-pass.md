# 行動版體驗改善

日期：2026-11-02。範圍：jymap 手機直向與橫向，桌面只受兩項共用修正影響。

## 驗收方式

用 Playwright 驅動 Chrome，以 390×844、360×640、844×390 三種視窗模擬觸控與 2 倍像素比，實際截圖並操作。這補上 [2026-10-29](2026-10-29-ux-implementation.md) 當時沒有截圖、最窄只到 485px 的缺口。

## 修正結果

| 問題 | 修正前 | 修正後 |
| --- | --- | --- |
| 點頁面任何地方都會套用時間篩選，手機與桌面都有 | 點搜尋框，事件由 257 掉到 31 | 只有真的拖過時間軸才更新範圍 |
| 手機開場視角 | 沿用桌面視角，只看到甘肅一帶約 5 個標記 | 390px 可見 203 個，360px 180 個，橫向 168 個 |
| 條件列寫「視野內 N 件」 | 數字是篩選結果，不是畫面內 | 改為「顯示 N 件事件」 |
| 縮放鈕 | 被搜尋框壓住，30×30px | 移到時間軸右上方，44×44px |
| 標記 popup | 與底部面板重複，又被控制列遮住 | 手機與橫向隱藏，內容都在面板裡 |
| 底部面板 | 固定 62dvh，人物模式地圖只剩約 134px | 預設 50dvh，可拖曳到收起或全高，點把手也可切換 |
| 返回鈕 | 控制列與面板各一個 | 面板開啟時隱藏控制列 |
| 條件列 | 換行後高達 106px | 固定一列，可橫向捲動 |
| 橫向畫面 | 上下控制項佔約 77% 高度 | 搜尋靠左，時間軸降為 106px |
| 《鴛鴦刀》區間標籤 | 區間只有 25px，截成「《」 | 窄區間改用短標籤，完整內容留在 aria-label |
| 觸控目標 | 關閉鈕 32px、來源連結 20px、標記 22px | 都至少 44px，只有面板把手是 36px 高、全寬 |

## 行動裝置基礎

- 全版高度改用 `100dvh`，避免 iOS 網址列遮住時間軸。
- 加 `viewport-fit=cover` 與 `env(safe-area-inset-*)`，瀏海與底部橫條不遮內容。
- 搜尋框字級改 16px，避免 iOS 聚焦時自動放大。
- 搜尋清單高度改看 `visualViewport`，加上 `interactive-widget=resizes-content`，鍵盤出現時清單仍能捲到底。

實際操作確認：拖曳把手在 390×844 依序停在 150、422、832px；縮放鈕可點；拖曳時間軸仍會更新範圍；三種視窗都沒有頁面錯誤；桌面的搜尋、拖曳與 popup 不變。

## 限制

- 只用 Chrome 模擬，沒有在實體 iPhone 或 Android 上測。安全區、虛擬鍵盤與 iOS 自動放大需要實機確認，模擬環境看不到鍵盤。
- 本次新增的樣式讓 `app.component.scss` 超過元件預算 1.52 kB，建置只有警告，尚未拆分。

未處理：人物或地點重疊的標記沒有做分群；時間軸泡泡與朝代標籤在中央仍有些微重疊。
