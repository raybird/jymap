# 《越女劍》第二輪複核

日期：2026-11-02。第三階段第二十二批。

結果：8筆都補上新修版正文來源，年份、座標與標籤都不改，情節抽查沒有發現錯誤。全站257筆、待查80筆不變。

## 方法與限制

- 金庸武俠網沒有收這一篇，九九藏書以腳本讀取回傳403。2026-11-02改取[GitHub OliverCWY/JY倉庫標稱新修版的全文](https://github.com/OliverCWY/JY/blob/master/Markdown/新修版/越女剑/越女剑.md)，約1.7萬字，[來源清單](2026-11-02-yuenv-source-manifest.json)列字數與檔案雜湊，不收錄全文。第一輪採三聯版分段，本批補上新修版，但個人倉庫的版本標示不等於印本校勘。
- 全篇短，時間線索都已掃過；不是逐字校勘。
- [作品條目](https://zh.wikipedia.org/wiki/越女劍)只寫春秋末年吳越爭霸，沒有事件年表。

## 年代

全文只有一個把前後段連起來的年距：鑄劍之後「三年之後，勾踐興兵伐吴」。所以前段前476、結尾前473的算法成立，但前473本身是史實代表值，小說沒有寫年，`代表年份`都保留。

其他時間線索都不改變結論：「三年之前」是薛燭回述風胡子來訪；阿青十三歲是更早的回述，當時約十六七歲；「兩三年」是鑄劍的估計。結尾「春夜溶溶」只是場景季節，小說把興兵、兩戰與滅吳連敘，不能用來比對史實月份。
