# 《碧血劍》第二輪複核

日期：2026-11-02。第三階段第二十批。

結果：18筆都補正文依據，金蛇洞130由1636改1637，舊資料佔位解除；069、209、210移除`代表年份`。座標與朝代不改，情節抽查沒有發現錯誤。全站257筆、待查80筆不變，年份佔位由35降為34，推算年份由195增為196。

## 方法與限制

- 2026-11-02取得[金庸武俠網標稱新修版](https://www.jinyongbbs.com/jyxx/bxj/)二十回加評傳、後記，共68頁、約54萬字，[來源分頁清單](2026-11-02-bixue-source-manifest.json)列網址、擷取字數與HTML雜湊，不收錄全文。
- 全書以紀年、年齡、年距、月份季節做關鍵字掃描，再讀決定年份的段落。不是逐字通讀，也不是印本校勘。
- [作品條目](https://zh.wikipedia.org/wiki/碧血劍)只寫崇禎年間（1628至1644）與在華山習武十年餘，沒有事件年表；[袁承志條目](https://zh.wikipedia.org/wiki/袁承志)寫父親遇害時七歲。中段年份由正文推算。

## 金蛇洞

[2026-10-30補查](2026-10-30-yitian-bixue-chronology-followup.md)認為十三、十四歲混用，不能換成1637，並保留1636佔位。這次補上兩條線索，判斷改變：

| 線索 | 正文 | 推得 |
| --- | --- | --- |
| 七歲 | [第2回應松：袁督師遇害時公子七歲](https://www.jinyongbbs.com/jyxx/bxj/1247.html) | 1630年七歲，1633年十歲，與第2回「十歲左右」相合 |
| 十三歲 | [第3回「一晃三年」十三歲，這年端午傳劍](https://www.jinyongbbs.com/jyxx/bxj/1248.html) | 1636年 |
| 初冬 | [第3回木桑住半年到初冬，才遇雙猿](https://www.jinyongbbs.com/jyxx/bxj/1248_2.html) | 1636年初冬起 |
| 發現洞穴 | 同頁養七八天後「越養越馴」，「這一天」才發現 | 初冬之後一段時間 |
| 十四歲 | [第4回「在十四歲上無意中發現鐵盒」](https://www.jinyongbbs.com/jyxx/bxj/1249.html) | 1637年 |

十三歲是端午時的年齡，十四歲是洞穴之後的年齡，兩者並不矛盾。若從1633年底上山起算「一晃三年」，端午落在1637，同樣得到1637。舊值1636只對應十三歲，改為1637，移除`舊資料佔位`，加`推算年份`、`代表年份`，保留`年代待考`，因為計齡與跨年仍有一年誤差。

## 已知年代問題

- 下山年份只由「十餘年」與第8回夏天、第11回七月倒推，沒有明載，所以第5至10回各筆保留`代表年份`。
- 第1回張朝唐一線的年歲與本文無關，不納入計算。
