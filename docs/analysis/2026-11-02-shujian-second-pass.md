# 《書劍恩仇錄》第二輪複核

日期：2026-11-02。第三階段第二十一批。

結果：16筆都補正文依據，年份、座標與朝代都不改，情節抽查沒有發現錯誤。13筆有季節鏈夾在單一年內，移除`代表年份`。全站257筆、待查80筆不變。

## 方法與限制

- 2026-11-02取得[金庸武俠網標稱新修版](https://www.jinyongbbs.com/jyxx/sjecl/)二十回加附篇、後記，共61頁、約53萬字，[來源分頁清單](2026-11-02-shujian-source-manifest.json)列網址、擷取字數與HTML雜湊，不收錄全文。
- 全書以紀年、年距、月份季節做關鍵字掃描，再讀決定年份的段落。不是逐字通讀，也不是印本校勘。
- [作品條目](https://zh.wikipedia.org/wiki/書劍恩仇錄)只寫乾隆年間，沒有事件年表。年份都由正文推算。

## 內容核對

## 已知年代問題

- 第5回在甘肅初秋，第7回已到杭州，中秋前趕完全程，行程偏緊。正文都寫在同一個秋天，不影響年份。
- 史實乾隆南巡與黑水營之圍的月日與小說不同，本站不以史實倒定小說年份。
