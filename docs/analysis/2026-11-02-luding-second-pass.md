# 《鹿鼎記》第二輪複核

日期：2026-11-02。第三階段第十九批，《倚天》改動超過3筆後改做全本。

結果：33筆都補正文依據，年份、座標與朝代都不改，情節抽查沒有發現錯誤。161、162加`代表年份`，並註明與wiki年表的落差。全站257筆，待查80筆不變。

## 方法與限制

- 2026-11-02取得[金庸武俠網標稱新修版](https://www.jinyongbbs.com/jyxx/ldj/)五十回加兩篇附文，共173頁、約124萬字，[來源分頁清單](2026-11-02-luding-source-manifest.json)列網址、擷取字數與HTML雜湊，不收錄全文。
- 全書以紀年、年齡、年距、月份季節做關鍵字掃描，再讀決定年份的段落。不是逐字通讀，也不是印本校勘。
- [作品條目](https://zh.wikipedia.org/wiki/鹿鼎記)有逐年的「事件年表」，本書年份全部以它為準；本站除036外都與它一致。

## 已知年代問題

- **揚州段（161、162）：** 第38回上諭要韋小寶繞道王屋山再往揚州，是同一趟行程。第40回吳三桂尚未起兵，[第41回回京途中](https://www.jinyongbbs.com/jyxx/ldj/1542.html)才傳來起兵與詔書，詔書稱「本年七月」自請搬移。依史實這在1673年，揚州段也可能在1673年，wiki列1674。本站不以史實倒定小說年份，暫從wiki，說明已註明。
- **雅克薩（038）：** 正文由台灣回京後隨即出征，秋冬破城，下一個夏季就到尼布楚議和，等於把1683至1689壓成約一年。wiki年表沒有列破城年，1685只是歷史戰事的代表值。
- **「去年」：** [第39回韋小寶說到昆明是去年](https://www.jinyongbbs.com/jyxx/ldj/1540_3.html)，第38回孫思克也說去年，按年表應隔三年。前者是韋小寶吹噓陳圓圓時的話，不作錨點。
- **036：** wiki把擒鰲拜列1668，第5回作者註引《清史稿》康熙八年。本筆是歷史背景，保留1669，168等小說線跟年表。
- 第46回林興珠說鄭經「今年正月」去世，但說話已在平台之後；俄國火槍手之亂的史實年也與1672不同。兩者都是小說改動，不影響年份。
