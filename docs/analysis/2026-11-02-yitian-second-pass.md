## 方法與限制

- 2026-11-02取得[金庸武俠網標稱新修版](https://www.jinyongbbs.com/jyxx/yttlj/)四十回加後記，共130頁、約99萬字，[來源分頁清單](2026-11-02-yitian-source-manifest.json)列網址、擷取字數與HTML雜湊，不收錄全文。
- 全書以紀年、年齡、年距、月份季節做關鍵字掃描，再讀決定年份的段落，並抽查26筆的人物與情節。不是逐字通讀，也不是印本校勘。
- 寫入腳本要求每個新增來源都能在該頁找到錨點句，19筆全數通過。
- [作品條目](https://zh.wikipedia.org/wiki/倚天屠龍記)只寫到景定元年（1260）序幕及至元二年三月廿四日（1336年5月5日）開場；[張無忌條目](https://zh.wikipedia.org/wiki/張無忌)寫約二十歲出谷，沒有中後段年份，也沒有出現至正年號。1336之後的年份都是本站由正文累計推算，不是wiki或原文明載。

若要維持舊年份，必須把入幽谷提早到1351年，但第14回夏末秋初已在1350年底之後，第15回過年又在其後，做不到。

人物年距大致相合，但口述不精確，所以只作旁證，不作錨點：第17回二十一歲、第18回與殷梨亭相別九年、第21回分手六年，都合1357年；第16回入谷十五歲、第22回與周芷若別八年多，算來差約一年。

## 空見之死

事件卡原寫「缺乏將這些相對線索連到確年所需的間隔」，這句是錯的，[2026-10-30補查](2026-10-30-yitian-bixue-chronology-followup.md)只讀了第7、8回，漏了第6回。

- [第6回](https://www.jinyongbbs.com/jyxx/yttlj/1390.html)謝遜在王盤山後自述「今年我四十一歲，十三年來」，又說二十八歲立誓，41減13正好是28，滅門約在1323年。
- [第7回](https://www.jinyongbbs.com/jyxx/yttlj/1391_3.html)滅門後三年、五年、兩年，最早到約1333年，之後才找不到成昆、四處作案、在洛陽遇空見。
- [第8回](https://www.jinyongbbs.com/jyxx/yttlj/1392.html)空見死後才有王盤山奪刀，上限是1336年。

舊值1320早於滅門，不能成立。補查文件當時排除的誤讀仍然正確：這些年距不能算出確年，空見所說的三年是成昆的學藝期間。

採1334為區間內代表值，理由是1333只是下限，其後還有養傷、尋人與半年作案。移除`舊資料佔位`，加`推算年份`、`代表年份`，保留`年代待考`，所以待查數不變。這筆不用`eraEstimate`：區間帶是一部作品一條，點擊會篩選整部《倚天》，只有一筆、三年寬的區間不適合。

## 已知年代問題

- 第18回隆冬與第23回「驕陽如火」只隔半月餘，第34回六月十五婚變當天又寫「此時正當仲春」。這兩處正文自身矛盾，不影響年份，事件說明已註明。
- 正文後段史事與史實不同步：第36回回述朱元璋取集慶，史實是1356年（029），第34回韓山童仍在世，史實卒於1351年。本站不以史實倒定小說年份。
- 三十九回後正文未寫過年，205以第40回秋末定在1359年。
